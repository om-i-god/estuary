# estuary Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A norns script + SuperCollider engine that plays a whole relaxing ambient set by itself — sparse motifs, bright warm harmony, field-recording water swells — steerable like gradient.

**Architecture:** A re-voiced fork of gradient (`~/dev/gradient`): same shape (main script + clock loop, `lib/conductor.lua` arc, `lib/harmony.lua` voice-leading, `lib/outs.lua`, `lib/listen.lua`, `lib/gridui.lua`, `lib/visuals.lua`, own `Engine_*.sc`, headless `test/sim.lua`), with drums/dub stripped and three new pieces: `lib/motifs.lua` (sparse phrase generator), `lib/nature.lua` (sample folders + swell/moment scheduler) and an anti-goal rule checker that the sim runs over two hours of music. Pure-Lua modules get unit tests in `test/unit.lua`; the engine is compiled and rendered on the Mac via `test/sc/run.sh`.

**Tech Stack:** Lua 5.3/5.4 (norns), SuperCollider 3 (Mac has sclang at `/Applications/SuperCollider.app`), ffmpeg, rsync/ssh to norns.

**Spec:** `docs/superpowers/specs/2026-11-02-estuary-design.md` (read it first; every "never busy / never dark" number below comes from it).

## Global Constraints

- Repo: `~/dev/estuary`, local git only, no remote. Copy gradient files as starting points; never edit `~/dev/gradient`.
- Commit messages end with `Co-Authored-By: Claude Opus 5.5 (1M context) <noreply@anthropic.com>`.
- Lib files load with `include("lib/foo")`, never `require`.
- No `.sc` file under `test/`. The CroneEngine stub stays `test/sc/CroneStub.stub`. Deploys rsync with `--exclude test --exclude docs --exclude audio --exclude tools`.
- SynthDef arg names must stay unique after `t_` stripping (no `t_gate` beside `gate`).
- Shared `local` state is declared at the top of its section, before any function that references it.
- Engine class `Engine_Estuary`, SynthDef prefix `est_`, so nothing collides with gradient on the same norns.
- **Never busy:** ≤ 3 motifs sounding at once; each motif has 3–7 notes plus ≥ 1 rest; no onset gap inside a motif shorter than an 8th; a mutation changes one thing.
- **Never dark:** modes are ionian, lydian, mixolydian, major pentatonic, passing pentatonic and dorian only; chord colours are major, add9, 6/9, sus2, maj7, quartal, open 5th+9; minor-quality chords (vi, iii, dorian i, passing iv) only in warm voicings (m7, rootless m9, open 5th+9); no diminished/augmented triads; no adjacent semitone between upper chord voices; maj7 spread; no distortion/saturation in the engine.
- Avoid notes (pc a semitone above a chord pc and not itself a chord pc) last ≤ 1 beat and never end a motif.
- Defaults: tempo 72 BPM (range 50–100), phrase 16 bars (8/16/32), track 12 min (6–30), chord hold 8–32 bars, water swells 1–2 per set cycle, set cycle 20–40 min.
- Samples on norns at `dust/audio/estuary/{water,birds,wind,room}/`; missing folders skip their moments silently.
- Every melodic part (motifs, pad, pedal) has output internal / midi / both. Nature + FX internal only.
- Visual themes are estuary's own — port nothing from causeway or gradient's visuals.

## Review Focus

1. **Empty or partial sample folders** (fresh install, no `water/`): the set must still run and the K3 tide must no-op with a screen message, not error. → test in Task 5.
2. **Tempo extremes (50 and 100 BPM)** with long motifs: cycle lengths in beats must still be honoured and note-offs must not pile up. → sim run at both tempos in Task 7.
3. **Hand mutes/solos while a swell is thinning the texture:** unmuting must not push active motifs past 3. → rule check covers mutes in Task 7.
4. **Key/mode change by hand mid-swell or mid-morph** (hold K2 + E2/E3): chords re-voice without a semitone rub or a dim triad. → unit test in Task 2.
5. **MIDI-only routing** for a part: the conductor's thinning still applies to MIDI velocity / note gating, so the external synth gets thinned too. → sim assertion in Task 8.

### Task 3: Motifs

**Files:**
- Create: `lib/motifs.lua`
- Test: `test/unit_motifs.lua`

**Interfaces:**
- Consumes: `T.MODES`, `T.degree`.
- Produces:
  - Motif table: `{events = {{dur = eighths, tone = chord-tone index | nil, pass = +1|-1|nil}, ...}, cycle = total eighths, oct, pan, voice (1 rhodes 2 bell 3 sine 4 marimba), bright (0..1), send (0..1), pos = 1, left = 0, intro = cycles remaining}`. `tone == nil and pass == nil` = rest.
  - `M.new(slot) -> motif`; `M.mutate(m) -> kind` (`"swap"|"rest"|"rotate"`); `M.step(m) -> event | nil` (call once per 8th; returns the event that starts on this 8th, else nil); `M.realize(m, ev, chord, mode, root_pc) -> midi`.

Rules (algorithm the tests pin):
- 3–7 sounding events and ≥ 1 rest; durations in eighths from `{2,2,2,3,4,4,6,8}` plus an occasional `{1,1}` pair (two 8ths, both sounding, ≤ 1 pair per motif); **cycle in beats is odd**: total eighths = 2 × one of `{7,9,11,13,15}` (pad the last rest to hit it).
- Sounding events are chord-tone indices 1..6 moving mostly by ±1 (≥ 70% of moves), leaps ≤ 3 indices; the span fits in about an octave.
- `pass` events: a scale step above/below the previous sounding note, only with `dur ≤ 2`, never last sounding event, never first. In pentatonic modes `pass` lands only on `melody ∪ passing` pcs (realize snaps to the nearest allowed pc, preferring down).
- `realize`: tone → `chord[((i-1)%4)+1] + 12*((i-1)//4) + m.oct`, folded into 55..91; pass → nearest scale/melody pc one step from previous realized note. In pentatonic modes a `tone` that lands outside `melody` is replaced by the nearest chord tone that is inside it.
- Mutation: exactly one of swap one sounding tone (±1 index), lengthen/shorten one rest by 2 eighths (keep cycle odd in beats by adjusting the same rest by 2), or rotate events by one. `M.new` sets `intro = 2`.
- Registers by slot: oct `{0,12,0,12}` + small random; pans spread ±0.2..0.6.

- [ ] **Step 1: Write failing tests** (1000 seeds):
  - `shape`: sounding count 3..7, rests ≥ 1, `cycle % 2 == 0` and `(cycle/2) % 2 == 1`, no event `dur < 1`, `{1,1}` pairs ≤ 1, min onset gap ≥ 1 eighth.
  - `passing is short`: every `pass` event has `dur ≤ 2` and is not the last sounding event.
  - `mutate is one change`: diff before/after touches exactly one event's tone, or one rest's dur, or is a rotation; shape test still holds after 50 mutations.
  - `avoid notes`: realize every event against 50 random bright chords; any realized pc that is a semitone above a chord pc and not itself a chord pc came from a `dur ≤ 2` event that isn't last.
  - `pentatonic`: in mode 4, every realized pc ∈ `{0,2,4,7,9}` + root offset; in mode 5, pcs `{5,11}` (relative) only on `pass` events.
- [ ] **Step 2:** Run → FAIL.
- [ ] **Step 3:** Implement.
- [ ] **Step 4:** Run → ok.
- [ ] **Step 5:** Commit `motifs: short odd-cycle phrases with rests, one-change mutation`.

### Task 6: Conductor

**Files:**
- Create: `lib/conductor.lua` (gradient's structure: `C.SECTIONS`, `C.new_track`, `C.bar`, `C.phrase`, `C.decide`, `C.mutate`; strip fills/kick/pump/throws)
- Test: `test/unit_conductor.lua`

**Interfaces:**
- Consumes: `H.*`, `M.*`, `N.*`.
- Produces state the main script reads: `S.bloom`, `S.section`, `S.gain[part]` (0..1, faded) for parts `motif1..motif4, pad, pedal`, `S.cap` (1..3), `S.sounding = {slot booleans}`, `S.motifs[1..4]`, `S.breathe_until` (bar), `S.muted[part]`, `S.soloed[part]`; functions `C.new_track(S, seed, move_key)`, `C.bar(S)`, `C.phrase(S)`, `C.breathe(S)`, `C.tide(S) -> ok, msg`, `C.nudge(S, d)`.

Rules:
- Track sections (fractions; bloom e0→e1): arrival 0.15 (0.05→0.30), bloom 0.25 (0.30→0.85), tide 0.15 (0.50→0.15; calls `N.swell` at its start), return 0.25 (0.40→0.75), settling 0.20 (0.60→0.00). Track length in bars = minutes × tempo / 4.
- Set mode: cycle length drawn 20–40 min; bloom = slow sine-ish swell plus random walk; troughs reach 0.05; schedule 1–2 swells per cycle at random bars outside the top 20% of bloom; moments at most once every 3 phrases (probability scales with the nature "moment frequency" param).
- `S.cap`: bloom < 0.3 → 1, < 0.6 → 2, else 3. While any motif has `intro > 0`: cap ≤ 2. While `N.state ∈ {rising, held}` or `bar < S.breathe_until`: cap = 1. **The rule `#sounding ≤ 3` is enforced last, after mutes and solos** (Review Focus 3): solos/unmutes can choose *which* motifs, never raise the count above `S.cap`.
- Which slots sound: keep currently sounding ones (stability); fill free capacity with the lowest-index slot not muted; fades take 4–8 bars (`gain` moves ≤ 1/4 per bar up, ≤ 1/8 down).
- Pad enters at bloom ≥ 0.15, pedal at 0.45–0.9 only; both thin under a swell (pad gain × 0.5).
- Phrase edge: each sounding motif `M.mutate` with p = 0.5; with p = 0.08 retire the oldest motif and `M.new` it. `intro` counts down per completed cycle.
- `S.swell_change`: apply one of new motif (retire one), `H.next_prog`, or key move ±5/±7 semitones (not while LISTEN follow is on); clear the flag.
- `breathe`: `S.breathe_until = bar + 8`. `tide`: proxies `N.swell`.

  - `cap holds`: every bar, `#sounding ≤ S.cap ≤ 3`; under rising/held swell or breathe, `#sounding ≤ 1`.
  - `mutes cannot exceed cap`: random mute/solo/unmute toggles each bar; `#sounding ≤ 3` still.
  - `track arc`: sections appear in order; bloom at the last bar ≤ 0.05; exactly one swell started in track mode.
  - `set swells`: swells per completed cycle ∈ {1, 2}.
- [ ] **Step 2:** Run → FAIL. **Step 3:** Implement. **Step 4:** Run → ok.
